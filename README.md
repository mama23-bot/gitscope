# GitScope

**Explore your Git history. Understand every commit. Master Git visually.**

Локальное desktop-приложение: визуальный исследователь Git-истории и интерактивный
учебник Git в одном окне. Работает полностью офлайн, без телеметрии и платных API.

---

## Что уже работает (Milestone 1)

### Repository Explorer
- Открытие локального репозитория и список недавних.
- Граф коммитов: цветные ветки, merge-коммиты, HEAD, теги.
- Виртуализированный список — можно листать историю в десятки тысяч коммитов.
- Панель коммита: автор, дата, сообщение, статистика, список файлов.
- Diff-viewer с подсветкой добавлений и удалений.
- Фильтры по автору, ветке и тексту (сообщение, автор, хеш).
- Демо-репозиторий в один клик — с ветками, merge и тегом.

### Playground
- Настоящий `git` в изолированной песочнице.
- Терминал с историей команд и подсказками для типичных ошибок.
- Живой граф, который обновляется после каждой команды.
- Шпаргалка команд.

### Learn
- Урок «Ветки и merge»: 5 шагов, проверка по состоянию репозитория.
- Прогресс, XP и сохранение между запусками.
- Каркас уровней: основы, ветки, конфликты, rebase, восстановление, продвинутое.

### Каркас приложения
- Тёмная тема, sidebar, статус-бар, роутинг.
- Разделы Analytics, Search, Compare и Challenges — с честными заглушками.
- Настройки: версия git, папка данных, описание модели безопасности.

## Запуск

### Обычный путь (MSVC)

```powershell
npm install
npm run tauri dev
```

### Этот компьютер (GNU-тулчейн)

В окружении без MSVC Build Tools используется GNU-тулчейн. MinGW-утилиты не
понимают кириллицу в путях, поэтому проект подключается через ASCII-диск `X:`,
а линкером выступает `rust-lld`.

```powershell
winget install BrechtSanders.WinLibs.POSIX.UCRT
npm install
npm run tauri:dev
```

Скрипт `scripts/dev.ps1` сам настраивает `PATH`, `RUSTUP_TOOLCHAIN`, `RUSTFLAGS`
и `subst X:`. Для сборки установщика — `npm run tauri:build`.

### Превью интерфейса в браузере

```powershell
npm run dev
```

В браузере приложение работает на демо-моке: реальные команды git не выполняются,
но весь интерфейс и навигация доступны.

## Безопасность

Модель безопасности встроена в Rust-слой, а не в предупреждения:

- **Репозитории пользователя — только чтение.** Разрешён фиксированный набор
  команд (`log`, `show`, `diff`, `status`, `for-each-ref`, `rev-parse`, …).
  Любая попытка записи отклоняется.
- **Все изменения — только в песочницах** внутри папки данных приложения.
- **Сеть отключена.** `clone`, `fetch`, `pull`, `push`, `remote`, `submodule`
  запрещены в песочнице.
- **Изоляция окружения.** Свой `GIT_CONFIG_GLOBAL`, `GIT_CONFIG_NOSYSTEM=1`,
  пустой `core.hooksPath`, `core.autocrlf=false`, без пейджера и интерактивных
  запросов.
- **Защита от побега.** Блокируются `-C`, `--git-dir`, `--work-tree`, `--exec`,
  `--output`, `--no-index` и другие флаги, выходящие за пределы песочницы.
- **Без shell.** Командная строка разбирается на аргументы и передаётся в `git`
  напрямую — инъекции невозможны.

## Архитектура

```
React (features/*) ── typed IPC ──> Rust
                                    ├─ git/runner.rs    запуск git, таймауты, env
                                    ├─ git/policy.rs    allowlist команд
                                    ├─ git/repo.rs      история, refs, diff, status
                                    ├─ git/sandbox.rs   сценарии и команды песочницы
                                    └─ db/              SQLite: прогресс, кэш, настройки
```

- **Граф коммитов** раскладывается по дорожкам собственным алгоритмом
  (`src/lib/graph-layout.ts`) в Web Worker и рендерится SVG с виртуализацией.
- **Проверка заданий** — декларативные предикаты по снимку состояния репозитория
  (`src/lib/validators.ts`), а не сравнение введённых команд. Ученик может прийти
  к цели любым корректным путём.
- **Сценарии** описаны данными (`src/content/scenarios`, `src/content/lessons`) и
  применяются Rust-слоем через настоящий git.

## Тесты

```powershell
npm test
```

Покрыты раскладка графа (линейная история, ветвление, octopus-merge) и
валидаторы уроков. Rust-тесты git-движка и политики команд:

```powershell
cd src-tauri
cargo test --no-default-features
```

Флаг `--no-default-features` отключает Tauri: git-движок собирается и тестируется
без WebView2 и UI-фреймворка.
